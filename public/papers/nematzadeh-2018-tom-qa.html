Evaluating Theory of Mind in Question Answering

A bAbI-style QA dataset — ToM-bAbI — built directly on the Sally-Anne and Ice-cream-Van false-belief experiments from developmental psychology, with true-, false-, and second-order-false-belief stories and four question types (memory, reality, first-order, second-order) that mirror the control questions psychologists use to rule out a lucky guess. Four memory-augmented QA models that were near-state-of-the-art on bAbI — MemN2N, Multiple Observer, EntNet, RelNet — all fail to clear the paper's own 95% success bar on the full ToM dataset, and every model loses further accuracy once distractor sentences are added at test time.

// the gap

What problem is this solving?

Weston et al.'s bAbI dataset gave neural QA models 20 toy reasoning tasks, but "only a few years after their release, existing models fail at only one or two (out of 20) tasks," and "all except two of the reasoning tasks in this dataset only require transitive inference." None of the 20 tasks ask a model to reason about what another agent believes — the capacity, well-studied in developmental psychology as theory of mind, to recognize that someone else's beliefs can differ from reality.

Grant et al. (2017) took a first step, adapting the Sally-Anne false-belief test into a bAbI-style dataset to check whether the end-to-end memory network (MemN2N) could answer questions like "where does Sally think the milk is?" when Sally's belief about the milk's location doesn't match reality. But that dataset "only considered first-order beliefs (e.g., Sally's belief about the location of milk)," leaving out second-order beliefs — beliefs about another agent's beliefs, e.g. "Anne's belief about Sally's belief about the location of the milk" — which Perner and Wimmer's 1985 Ice-cream-Van experiments show is a harder, later-developing capacity in children. It also scored success as a single correct answer to one question, the same weakness the authors identify in bAbI itself: "this does not guarantee that a model has an understanding of the state of the world," since even in the original psychology experiments, children are asked several questions (e.g. "where is the milk really?") specifically so a correct belief answer can't be attributed to chance.

This paper designs a new dataset to close both gaps at once: true-, false-, and second-order false-belief tasks, each paired with four question types (memory, reality, first-order, second-order) so a model's answer to the belief question can be cross-checked against whether it also tracks the plain state of the world.

// how it works

The method

The task design is lifted directly from two classic false-belief paradigms. In the Sally-Anne experiment (Baron-Cohen et al., 1985), Sally puts a marble in her basket and leaves the room; while she's gone, Anne moves the marble to her box; when Sally returns, participants are asked a belief question ("where will Sally look for her marble?"), a reality question ("where is the marble really?"), and a memory question ("where was the marble in the beginning?") — the last two exist purely to confirm a correct belief answer isn't due to chance. Perner and Wimmer's (1985) Ice-cream-Van experiment extends this to second-order belief: John doesn't know that Mary has learned the ice-cream van moved, so he holds a false belief about what Mary believes, tested by "where does John think Mary goes to get icecream?"

The dataset is generated from grammars, following Grant et al. (2017)'s approach of formalizing each reasoning task the way Weston et al. (2016) formalized bAbI. Three task types are generated — true-belief (an agent observes the world, so her belief matches reality), false-belief (the agent is absent when the world changes, so her first-order belief is wrong), and second-order false-belief (a second agent doesn't know the first agent has observed a change, so the second agent's belief about the first agent's belief is wrong). Each of the three task types is paired with four question types — memory, reality, first-order, second-order — producing 12 task/question combinations, with each generated example carrying a single question drawn from one combination.

Table 3 in the paper gives the correct answer to each of the 12 task × question combinations. For the true-belief and false-belief tasks, the first-order and second-order questions happen to have the same correct answer — but they diverge on the second-order false-belief task, "because Anne has a false belief about Sally's belief." The paper deliberately assumes all containers are transparent — "whenever an agent enters a location, they become aware of the objects true location" — specifically to stop a model from learning to associate a fixed answer with a surface phrase like "Sally looks inside the pantry," instead of tracking belief state.

Two dataset variants are released: ToM-easy, where each story contains exactly one task, and ToM, where up to 5 tasks are randomly grouped into a single story (matching bAbI's story length) — at test time each ToM story has 4 tasks in its context but only one question at the end, so a model must also identify which task-question pair among several competing storylines is actually being asked about. Each dataset's training set has 10,000 examples per each of the 12 task/question combinations. Four published, near-state-of-the-art-on-bAbI models are evaluated: the end-to-end memory network (MemN2N; Sukhbaatar et al., 2015), the Multiple Observer model (Grant et al., 2017's extension of MemN2N with a separate memory module per agent, so an agent's memory only contains what that agent actually witnessed), the recurrent entity network (EntNet; Henaff et al., 2017), and the Relation Network (RelNet; Santoro et al., 2017). All models are trained jointly across task types (without noise) and evaluated separately per task/question pair, with hyperparameters selected on a validation set; following Sukhbaatar et al. (2015), "we consider a model successful only when its accuracy exceeds 95% across the entire task suite."

// what they found

The results

All four models hit 100.00% on ToM-easy without noise — the single-task-per-story setting is easy enough that none of the paper's diagnostic power shows up yet. The full ToM dataset is where the paper's design does its work: no model clears the 95% success bar. RelNet comes closest at 94.31%, followed by EntNet at 93.67%, Multiple Observer at 91.11%, and MemN2N at 82.38%.

Adding distractor sentences hurts every model. With a p = .1 probability of a random noise sentence appearing before each story sentence at test time, all four best models lose accuracy on both datasets — and RelNet, despite being the best performer on ToM, is also the most sensitive to it, dropping from 94.31% to 76.84% (a 17.5-point fall, the largest of the four). Multiple Observer — the model with a separate memory module per agent — is the most robust: its accuracy falls only from 91.11% to 87.43% on ToM and from 100.00% to 95.81% on ToM-easy, the smallest drop of any model on both datasets.

The box plots reveal what the aggregate numbers hide. On ToM-easy, MemN2N's median accuracy is close to 1.0 for memory, reality, and second-order questions, but drops to around 0.5 on the first-order question specifically for the false-belief and second-order-false-belief tasks — "this pattern is different from the empirical findings on people; the second-order question is harder than the first order one for people." The paper traces this to the model learning a shortcut rather than reasoning: when they altered the data so the first-order question's answer was (incorrectly) forced to match across both false-belief tasks, "the median accuracy is close to 1 for all conditions," suggesting MemN2N can memorize a distinction between two tasks but not generalize across three genuinely different ones.

Two patterns stand out. First, "all models fail the memory question for each task type" — even RelNet, the strongest model overall, answers "where was the milk at the beginning?" correctly only 34.9–78.5% of the time depending on task, which the authors call surprising since (unlike EntNet's inherently recency-biased recurrence) MemN2N, Multiple Observer, and RelNet "exhibit only a small positional bias." Second, MemN2N's worst score in Table 5 is the false-belief task's first-order question at 17.3% — the exact question-task pair the box-plot investigation above traces to the model failing to generalize past two memorized answer patterns. A memory-size ablation makes the same point from another angle: shrinking MemN2N's memory from 50 slots to 10 lifts its accuracy on "the hardest task of ToM (FB task with first order belief question) from 5.1% to 97.5%" — not because the model got better at reasoning about false belief, but because a 10-slot memory can only hold about two tasks at once, collapsing ToM back into something closer to ToM-easy.

// does it hold up?

The eval read

As a diagnostic, ToM-bAbI does exactly what a good diagnostic should: it takes four models that were near-state-of-the-art on bAbI and breaks them cleanly on a well-motivated new axis, false and second-order-false belief, while confirming via its memory/reality control questions that the models track ordinary facts fine. But the paper's own honesty about confounds — the memory-size ablation, the answer-pattern-memorization experiment — points to the harder question it doesn't fully close: is a hand-written grammar generating these stories a reliable way to test belief reasoning, or just a new surface pattern for a memory-augmented model to fit?

baselines

All four evaluated models (MemN2N, Multiple Observer, EntNet, RelNet) are 2015–2017 memory-augmented architectures that were already state-of-the-art or near-state-of-the-art on bAbI by the time this paper appeared (Aug 2018) — reasonable given the paper's framing as a stress test for exactly those near-SOTA bAbI models. One reporting convention is worth flagging, though: because MemN2N is “very sensitive to the network initialization,” the paper follows Sukhbaatar et al. in reporting, for each parameter set, the best result out of ten runs — so the headline MemN2N and Multiple Observer figures are max-of-ten selections, not expected performance, which is exactly why Figure 3's box plots sit well below them. The paper is transparent about this and inherits it rather than introducing it, but it makes the clean 100.00% on ToM-easy a weaker signal than it looks. Separately, there is no comparison to any architecture designed specifically for belief tracking beyond Grant et al.'s (2017) Multiple Observer, and no sequence-model or attention baseline beyond what these four already provide.

contamination

Not applicable in the pretraining-leakage sense — the stories are synthetically generated from a grammar, not scraped text. But the generator itself is the leakage vector the paper doesn't test: nothing here checks whether a shallow lexical or positional heuristic (ignoring belief entirely) could answer the false-belief questions. That is precisely the vulnerability Le et al.'s 2019 ToMi paper found the following year in this dataset's story-template generators.

what's missed

The Table 4 aggregate numbers alone would suggest RelNet is simply "the best model" on ToM (94.31%) — the per-question breakdown in Table 5 and the box plots in Figure 3 are what actually locate the failure: every model fails the memory question specifically, and MemN2N's collapse on the false-belief first-order question (17.3%) is traced by the authors' own follow-up experiment to answer-pattern memorization across only two of three task variants, not belief reasoning breaking down gracefully. The noise experiment also only perturbs test-time inputs — models are trained without noise and tested with it, so the reported "sensitivity to noise" conflates architectural robustness with an unaddressed train/test distribution shift.

would raise confidence

An explicit heuristic or rule-based solver baseline — ignoring belief state entirely — run against the released generator, to rule out the surface-pattern leakage the paper doesn't test for (which is exactly what ToMi supplied a year later); a human performance number on the QA-formatted stories themselves, rather than relying on the separate developmental-psychology literature on Sally-Anne and Ice-cream-Van as an implicit ceiling; and a version of the noise experiment where models are also trained with noise, to separate genuine architectural fragility from simple train/test mismatch.

// bottom line

ToM-bAbI is a careful, well-grounded translation of two classic false-belief experiments into a bAbI-style diagnostic, and it earns its citations by finding a real gap: models that were near-state-of-the-art on bAbI's 20 tasks all fail this paper's own success bar — accuracy above 95% across the entire task suite — with clear evidence some of that "failure" is actually pattern memorization rather than reasoning at all. Its main liability is the one shared by bAbI itself and flagged explicitly in this paper's own framing of the problem it's solving — a small, grammar-generated story space is only as good a test of reasoning as its generator is hard to game, and Le et al.'s ToMi (2019) showed this generator specifically could be gamed.

// takeaways

What to remember

  1. ToM-bAbI operationalizes the Sally-Anne (first-order) and Ice-cream-Van (second-order) false-belief experiments as bAbI-style QA stories with three task types (true-, false-, second-order-false-belief) and four question types (memory, reality, first-order, second-order), so a model's belief answer can be cross-checked against control questions the way developmental psychologists check whether children's answers reflect real understanding.
  2. All four evaluated models (MemN2N, Multiple Observer, EntNet, RelNet) reach 100.00% on the single-task ToM-easy dataset without noise, but none clears the paper's own 95% success threshold on the multi-task ToM dataset — RelNet comes closest at 94.31% — and every model loses further accuracy once distractor sentences are injected at test time, with RelNet's drop (94.31% → 76.84%) the largest of the four despite it being the strongest model on clean ToM.
  3. This is the paper Le et al.'s 2019 ToMi paper explicitly revisits: it found that ToM-bAbI's three story-template generators leak enough surface pattern that a rule-based solver ignoring belief entirely could answer the false-belief questions, motivating a redesigned generator and a stricter joint-accuracy evaluation protocol.
