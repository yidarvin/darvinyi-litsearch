Hallucination is Inevitable: An Innate Limitation of Large Language Models

A diagonalization proof, not an experiment: for any computable LLM there exists a computable ground-truth function on which every one of its trained states is wrong somewhere. That is a worst-case existence claim about adversarially chosen inputs — not a claim about how often real models hallucinate on natural prompts.

// the gap

What problem is this solving?

By 2024, "hallucination" — an LLM producing fluent but wrong output — had a large empirical literature: surveys taxonomizing its causes, benchmarks scoring it, and mitigation methods (retrieval augmentation, chain-of-thought prompting, self-verification) claiming to reduce it. None of that literature could answer a more basic question: can hallucination be eliminated in principle, or only ever reduced? An empirical study can't settle this — you cannot enumerate and test every possible input a deployed model might see, so no benchmark result, however good, rules out failure on some untested case.

A formal answer needs a formal definition of "correct," and the paper is upfront that this is where real-world semantics breaks down: what counts as a correct answer to an open-ended natural-language question is, as the authors put it, still an open problem in linguistics and philosophy of language. Rather than wait for that problem to be solved, the authors substitute a formal stand-in: a world built entirely out of computable functions, where "correct" has an exact, checkable meaning. The paper's central move is to prove its impossibility result inside that substitute world, then argue the result transfers outward because the substitute world is a (much simpler) part of the real one.

// how it works

The method

The formal apparatus (Definitions 1–4, Procedure 1) strips an LLM down to what actually matters for the proof: a ground-truth function f maps every possible input string s (a prompt) to the one correct output f(s); a formal world Gf = {(s, f(s)) | s ∈ S} is just that function's full input–output table; training samples T are a subset of Gf the model gets to see. An LLM h is treated, after training, as a total computable function — it must return an answer for every input, in finite time — and h[i] denotes the state of h after training on i samples. Crucially, Procedure 1 (train-then-deploy) places no bound on how many training samples or how much compute is allowed: training can run for arbitrarily many, arbitrarily long steps. The impossibility result that follows is not an artifact of a limited training budget.

Definition 4 is the paper's formal notion of hallucination, and its quantifier order is the whole ballgame: h hallucinates w.r.t. f if ∀i ∈ N, ∃s ∈ S such that h[i](s) ≠ f(s) — for every trained state of the model, no matter how much data it has seen, some input exists on which it's wrong. The paper's Question 1 asks the reverse: can h be trained so that ∃i ∈ N, ∀s ∈ S, h[i](s) = f(s) — some finite amount of training producing a state that is correct on literally everything? Flipping those two quantifiers is the entire distance between "achievable" and what the paper goes on to rule out.

The proof technique is Cantor-style diagonalization, and the construction (Theorem 1) is concrete: take any computably enumerable set of LLMs {h0, h1, …} — e.g. every polynomial-time-bounded model anyone could ever build — and re-index every trained state of every model in that family into one master sequence ĥ0, ĥ1, ĥ2, … via the Cantor pairing function. Feed ĥi the i-th string si in a fixed enumeration of all strings, and define the ground truth as f(si) = Δ(ĥi(si)), where Δ is a computable function guaranteed to return something different from its input (e.g. "the next string in the enumeration"). By construction, f disagrees with ĥi at exactly the point ĥi was tested — so every model/state in the entire enumerated family hallucinates against this one f. Theorem 2 tightens the construction (f(si) is defined to differ from every ĥj(si) with j ≤ i, not just ĥi) so that each model hallucinates on infinitely many inputs, not just one. Theorem 3 then removes the "enumerated family" restriction entirely: any single computable LLM h forms a (trivially enumerable) one-element set {h}, so Theorems 1–2 apply directly — for any computable h, some computable f (and a possibly different f′) exists against which every trained state of h hallucinates, on one input and on infinitely many. A worked instantiation, Theorem 4, builds a concrete adversarial linear order < over strings — an abstraction of ranking, chronological, or alphabetical ordering — on which any computable LLM eventually answers a comparison question wrong, however many prior comparisons it has been trained on.

An immediate corollary (Corollary 1) is that an LLM cannot use itself to eliminate its own hallucination: if some h′ could self-correct to hallucination-freedom on every f, that would contradict Theorem 3. The paper is explicit that this targets self-contained mitigation — chain-of-thought, self-reflection, self-verification — because those still route all of the model's information about f through the same {(s, f(s))} training channel. Methods that inject information outside that channel are explicitly carved out: Section 4.2 states plainly that retrieval-/knowledge-augmentation supplies the model with extra information about f "other than via training samples," so "Theorem 3 is inapplicable herein." The theorem binds pattern-completion from training pairs alone, not every possible mitigation strategy.

// what they found

The results

Table 3 turns the abstract theorems into a list of concrete hallucination-prone problem classes, tied to the time complexity an LLM is bounded by. For polynomial-time-bounded LLMs ("e.g., all existing LLMs"), the paper names four: a Combinatorial List task requiring an Ω(2n) solution (no extra assumption needed); Subset Sum and Boolean Satisfiability, both NP-complete; and entailment of propositional logic, co-NP-complete — the latter three guaranteed hallucination-prone only if P ≠ NP, which the paper flags as an assumption, not a proof. For exponential-time- and polynomial-time-bounded LLMs alike, Presburger arithmetic (requiring an Ω(22cn) solution) is unconditionally hallucination-prone. For any computable LLM regardless of runtime, the paper adds learning all computable linear orders (Theorem 4), solving all computable problems (Theorem 3), and entailment of first-order logic, which is undecidable outright.

Appendix C empirically probes the combinatorial-listing case with a task L(m, A): list every string of length m over alphabet A. Every model eventually fails as m grows, and the failures are not a context-window artifact — L(7, {a,b}) is only 27 = 128 strings, an 896-character answer, far shorter than any tested context window (GPT-4-Turbo's is 128,000 tokens):

GPT-4-turbo-2024-04-09 is the only model of the five to succeed through m=5 with this alphabet — but the paper notes it failed the equivalent task with a different alphabet, L(5,{x,y,z}), hence its result is marked with an asterisk rather than a plain success. Appendix D runs a linear-order task ω(m) — determine whether x $ y holds for binary numbers up to m, using an intentionally obfuscated notation ("$" for "<", "a"/"b" for "1"/"0") so models can't just recite a familiar ordering — and here every one of the 5 models fails every one of the 4 test cases at both m=1000₂ and m=10000₂: 20 of 20 cells are ✗. Appendix E runs the reverse experiment, R(m,n): return the n-th character of an m-character string. All 5 models succeed on R(m,1) for every tested m (16–1024); Llama 2 alone fails R(m,2) entirely; and every model fails R(m,5) once m reaches 256 or 1024 — the paper reads this as evidence that "training corpora have not covered enough training samples for counting and indexing," i.e. current models haven't even reached the (still-bounded) ceiling the theory allows for polynomial-time systems.

Section 4.4 and Appendix E also state what the theorems do not cover: Theorem E2 shows the set of functions on which a given LLM can be made hallucination-free is itself contained in a computably enumerable set (learnability has its own ceiling), while Theorem E3 gives the positive counterpart — for any computably enumerable class of target functions fixed in advance, some LLM can be built that's hallucination-free on every member of that class, given enough (but finite) training.

// does it hold up?

The eval read

There's no benchmark to audit here — the central claim is a proof, not a measurement — so the critique has to be about what the proof actually licenses, and the paper is more careful about this than its title suggests a casual reader would expect.

The theorem is an existence claim, not a rate claim, and the paper knows the difference. Theorem 3 says: for any computable LLM, some adversarial ground-truth function exists on which the model is always wrong somewhere. It says nothing about how often a well-trained model errs on the distribution of inputs it will actually see in deployment. The paper is explicit about this distinction in its own introduction: it name-checks Kalai and Vempala's parallel STOC 2024 result, "Calibrated Language Models Must Hallucinate," as providing "a statistical lower bound on the rate of hallucination for calibrated LLMs" — a genuinely different, and arguably more practically actionable, kind of claim. Xu et al.'s contribution is "comparably more general" only in the sense of applying to all computable LLMs unconditionally; it buys that generality by giving up any statement about frequency. A reader who cites this paper as evidence that hallucination is common, rather than merely unavoidable in the worst case, is citing it for something it doesn't claim.

The diagonalization argument is, by the paper's own account, a relabeling of a 57-year-old result. Theorem 3 is introduced with the words "hence the following theorem similar to [20]" — reference 20 is Gold's 1967 "Language Identification in the Limit," and Theorem 4's proof is described as "adapting results from [20]." The construction itself is the textbook Cantor-diagonalization-against-an-effective-enumeration argument the paper walks through explicitly in Section 3 (citing Cantor directly, twice). None of this makes the result wrong — old, well-understood machinery applied cleanly to a new framing is a legitimate and clear contribution — but it does mean the paper's genuine novelty is narrower than "hallucination is inevitable" suggests: it is (a) the reframing of Gold-style unlearnability as "hallucination," (b) the applied complexity-theoretic corollaries in Table 3, and (c) the empirical illustration in the appendices, not a new impossibility technique.

The paper pre-empts the obvious objection, in an appendix. The natural complaint about a diagonalization result is that it proves something already known — the set of all computable functions is not PAC-learnable, so of course no algorithm gets every input right. Appendix G is written to answer exactly that, and its subsections are titled for it — “PAC Unlearnability does not answer Question 1” and its online counterpart. Its Statement 1 renders PAC unlearnability as the claim that no polynomial-time algorithm finds a low-hallucination LLM in all formal worlds, for all input distributions — a statement about the learning procedure over a whole class, where Theorems 1–2 fix a single ground truth and defeat every LLM in the set against it. The paper states the distinction itself: “Statement 1 describes practical learnability within certain time complexity and error rate, while Statement 2 describes learnability regardless of those assumptions.” Whether it carries the weight the authors want is arguable, but the criticism “this is just unlearnability restated” is one the authors saw coming and answered in print.

The formal definition of hallucination is not the empirical one, and the gap matters for what the theorem's scope actually is. Definition 4 counts any deviation from f(s) as hallucination — there's no notion of "fluent" or "confident" built in, and no partial credit. That makes the formal definition both broader and narrower than the everyday meaning: broader because a single wrong character counts; narrower because refusal is explicitly carved out in Section 4.3 — "it can refuse to answer an arbitrary number of questions... If an LLM never answers, then it will never hallucinate." The guarantee only bites "useful" LLMs that eventually commit to an answer outside their training data. An LLM that hedges indefinitely trivially satisfies the formal never-hallucinates condition while being useless — a legitimate result of the formalization, but a real distance from what "an LLM that doesn't hallucinate" means in practice.

The empirical appendices validate Table 3's corollaries, not Theorems 1–3 themselves. Theorems 1–3 are proved by explicit construction, but the object constructed is a ground-truth function built from the model's own outputs at every state — so there is no single prompt that "tests" them. What Appendices C–E actually probe are the concrete, complexity-grounded tasks in Table 3 — combinatorial listing (needs Ω(2n) time), a deliberately obfuscated linear-order task, and character indexing — which is a fair and useful thing to test, but it's a different, narrower claim than the headline theorem, and the paper's own framing ("we empirically validate this statement," referring to the Table 3 row, not to Theorem 3 directly) is careful about which one it's demonstrating.

baselines

Not applicable in the usual sense — there is no empirical claim to beat. The comparison that matters is conceptual: this is a worst-case existence result, distinct from Kalai & Vempala's contemporaneous statistical-rate result, and the two are easy to conflate if you only read the title.

contamination

Not a risk for the theorems (they're proofs). The empirical appendices ran gpt-3.5-turbo-16k, gpt-4-0613, gpt-4-turbo-2024-04-09, and two Llama checkpoints between December 2023 and May 2024, against commercial APIs whose training data is undisclosed and which have since been deprecated — ordinary reproducibility caveats for that portion only.

what's missed

Any statement about hallucination rate on natural, non-adversarial inputs; probabilistic (rather than deterministic) ground truth, which Section 4.4 flags as its own limitation; and whether the diagonal-constructed adversarial f for any given model resembles anything a real user would actually ask.

would raise confidence

A companion analysis connecting the existence result to observed failure rates (the way Kalai & Vempala's rate bound does); a broader, more recent model set in the empirical appendices (five models, all pre-mid-2024, no open reasoning models); and a worked argument for how far real-world failure classes extend beyond the specific complexity-hard tasks named in Table 3.

// bottom line

The proof is sound and the framing is genuinely useful — the paper turns a decades-old inductive-inference impossibility result into a legible, complexity-theoretic checklist (Table 3) of tasks where LLMs are provably unreliable, and backs it with a small but clean empirical demonstration that current models fail on those tasks well before running out of context — though the authors read those failures as showing either that training corpora lack the samples or that the models “have not achieved the theoretical limits of their abilities,” not as the theorems being exercised. What it does not do, and does not claim to do, is quantify hallucination's severity, frequency, or practical reducibility on the inputs that actually matter — that is a different, complementary question the paper explicitly hands off to statistical work like Kalai & Vempala's.

// takeaways

What to remember

  1. The theorem is: for every computable LLM, there exists some computable ground-truth function against which every trained state of that model is wrong on some input (and, more strongly, on infinitely many). That's a worst-case existence claim about adversarially constructed inputs — not a claim that hallucination is frequent, or that it can't be reduced in practice on the inputs that actually occur.
  2. The mechanism is Cantor-style diagonalization against an enumeration of a model's trained states — a technique the paper itself ties directly to Gold's 1967 language-identification-in-the-limit result. Its practical payoff is Table 3's list of complexity-class-hard problems (SAT, Subset Sum, propositional-logic entailment, Presburger arithmetic, undecidable first-order entailment) where standard LLMs are provably unreliable — the first three conditional on the unproved P ≠ NP, the last two unconditional.
  3. The result explicitly does not bind mitigation strategies that feed a model information outside its {(s, f(s))} training pairs — retrieval augmentation and external tool use are carved out by the authors themselves — so "hallucination is inevitable" is a limit on unaided, self-contained pattern completion, not a blanket argument against every hallucination-mitigation technique in the literature.
