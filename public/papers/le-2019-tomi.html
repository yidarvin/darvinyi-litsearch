Revisiting the Evaluation of Theory of Mind through Question Answering

A hand-written, four-line rule solver reaches 100% on the ToM-bAbi false-belief benchmark without ever tracking a single agent's beliefs — because the story generator's own templates leak the answer. The fix, ToMi, randomizes the generator and forces models to answer all six question types about the same story jointly; under that joint-accuracy protocol, three memory-augmented QA architectures collapse specifically on false-belief questions (as low as 10.4% accuracy) while staying near-ceiling on everything else.

// the gap

What problem is this solving?

Developmental psychology has a clean test for theory of mind: the Sally-Anne false-belief test, where a child watches an object get moved while one agent isn't looking, then has to say where that agent will look for it (not where it really is). Grant et al. (2017) turned this into a machine-learning task by casting it as bAbI-style question answering — auto-generating short stories about agents moving objects between containers, then asking a model where an agent will look. Nematzadeh et al. (2018) extended this to second-order beliefs ("where does John think Mary will go?") and reported that memory-augmented QA models mostly fail on it. The authors call this benchmark family ToM-bAbi.

The paper's core claim is that ToM-bAbi's apparent difficulty is mostly an artifact of how its stories are generated, not evidence that a model needs any theory of mind to solve it. ToM-bAbi uses three separate, rigidly templated generators — one for true-belief stories, one for false-belief stories, one for second-order false-belief stories — each following a fixed sentence-order skeleton (Figure 1, left). That structure creates giveaways: the word "exited" only shows up in stories generated by the false-belief templates, so its mere presence signals which questions are even meaningful to ask; the answer to a first-order belief question is always found in the same relative sentence position (immediately before the agent's last "exited" event); memory questions always resolve to the very first sentence that places the object. None of this requires reasoning about what any agent actually believes — it only requires pattern-matching the generator's own regularities. A second, independent problem: ToM-bAbi asks only one question type per generated story, so a model's accuracy on a false-belief question for a given story is never checked against whether that same model also gets the reality/memory questions right for that identical story — leaving open the possibility that "solving" false-belief questions is disconnected from actually tracking the state of the world.

// how it works

The method

The paper first proves the bias exists, then fixes it in two independent ways: a new dataset generator, and a new evaluation protocol.

Proving the bias: Algorithm 1

The authors hand-write a four-branch rule-based "solver" (Algorithm 1) that inspects only surface lexical cues in the question and story — whether the question contains "beginning" (memory: return the location of the object's first occurrence), "really" (reality: return the location of its last occurrence), "look" (first-order: return the last occurrence before the agent's last "exited" event, if any), or "think" (second-order: same idea, checked against the first "exited" event). The rules never extract any information about which agent is which or what any agent has or hasn't observed — they are pure string-matching plus event-ordering heuristics. This solver reaches perfect accuracy on both ToM-bAbi's easy split and its harder split, which is the paper's proof that the benchmark's own generation process, not genuine belief-tracking, is what current QA models are latching onto.

ToMi: a randomized generator

To remove the exploitable regularities, ToMi replaces the three separate template generators with a single randomized story generator that can produce any of the three story types (true-belief / false-belief / second-order false-belief), sampled with rejection so the final dataset stays balanced across types without a generator-identity signal leaking through. On top of that, ToMi injects several kinds of noise that ToM-bAbi lacked: actions by unrelated distractor agents, distractor statements about irrelevant locations and objects (so raw mention-count is no longer informative), randomized ordering of the exit/move/re-entry actions that make a story a false-belief story, and randomization of which agent's belief is being queried. Figure 1 (right) shows resulting ToMi stories next to the rigid ToM-bAbi templates (left) — the story skeleton visible in every ToM-bAbi example (fixed distractor sentence, fixed enter/exit ordering) is gone.

Joint accuracy: a stricter evaluation protocol

Separately from the dataset fix, the paper changes what gets asked and how it gets scored. For every generated story involving two agents A and B and an object O, ToMi asks all of: Reality ("Where is O?"), Memory ("Where was O in the beginning?"), First-Order Belief for A and for B ("Where will A/B look for O?"), and Second-Order Belief for A and for B ("Where does A/B believe the other will look for O?") — six questions per story instead of one. A story only counts as solved if a model answers every one of its questions correctly:

AccJ(S) = 1|S|  Σs∈S  Πq∈Qs 1(âq = aq) // joint accuracy: a story only counts if EVERY question about it is answered correctly (Eq. 1)

This closes the loophole where a model could look competent by nailing the easy reality/memory questions while getting the false-belief question wrong (or vice versa) on the same underlying story.

// what they found

The results

Three architectures from the original ToM-bAbi lineage are evaluated: Memory Networks (MemNN; Sukhbaatar et al. 2015), Relation Networks (RelNet; Santoro et al. 2017), and Recurrent Entity Networks (EntNet; Henaff et al. 2017). Table 1 reports average accuracy over all questions on three datasets — the original easy split (ToM-easy), the original harder split (ToM), and the new ToMi — plus the joint accuracy (Eq. 1) on ToMi only:

The purely lexical Algorithm 1 solver is perfect on both original ToM-bAbi splits — confirming the bias claim. On ToMi, all three QA models keep a fairly high per-question average (77.2-90.6%), but their joint accuracy — requiring all six questions per story correct — drops sharply to 44.3-66.8%, with EntNet best (66.8%) and MemNN worst (44.3%).

Table 2 (MemNN only) breaks the per-question average down by question type across the three datasets, and it explains where ToM's original difficulty actually came from: MemNN's memory-question accuracy falls to 71.9 on ToM (versus 100.0 on ToM-easy) — the authors attribute this to ToM's longer stories exceeding the model's memory capacity for locating the object's first mention, not to any belief-reasoning failure. On ToMi, memory accuracy recovers to 98.90 and reality accuracy is 93.39, but first-order accuracy falls to 70.72 and second-order to 64.66 — the opposite pattern from ToM, where first-order (98.6) and second-order (95.3) were both near ceiling. In other words, ToM's difficulty was mostly a memory-capacity artifact; ToMi's difficulty is concentrated in exactly the belief-reasoning questions the benchmark is meant to test.

On non-false-belief question-story pairs — where an agent's belief happens to match reality — all three models do reasonably well (82.67-100.0%). On false-belief pairs specifically, every model falls off a cliff: MemNN drops to 12.62% (first-order FB) and 17.27% (second-order FB); RelNet to 10.40% and 17.81%; EntNet, the best performer, still only reaches 54.95% (first-order FB) and 36.55% (second-order FB). EntNet's relative edge is notable because it's the one architecture explicitly designed to maintain a running estimate of world state, which the authors read as a useful inductive bias for tracking false beliefs specifically — though even EntNet is still well under half accuracy on second-order false-belief questions.

// does it hold up?

The eval read

This is a diagnostic paper, not a leaderboard paper, and it's honest about that scope — but a few gaps are worth flagging for anyone citing ToMi as a solved-or-unsolved benchmark today.

baselines

All three tested models — MemNN (2015), RelNet (2017), EntNet (2017) — are the same memory-augmented, bAbI-lineage architectures Nematzadeh et al. (2018) had already tested a year earlier; none is a Transformer/attention-based reader, despite this paper appearing in late 2019 (after BERT). "State-of-the-art methods... fail" (the abstract's framing) is true only within the bAbI-style architecture family the field had been using for this specific task, not against contemporary QA models generally.

contamination

Not applicable in the usual sense — ToMi's stories are synthetically generated on demand, so there's no fixed test set to memorize. But the paper's own diagnostic cuts both ways: the same lexical/positional Algorithm 1 that perfectly solves ToM-bAbi still reaches 36.5% joint accuracy on ToMi using zero information about any agent (Table 1) — noticeably above what pure chance across a discrete container/location answer space would predict, and that measured result alone is the honest signal that some agent-blind regularity survives the fix. (Footnote 3's own comment — "a more elaborate set of rules could solve the tasks, but would require to take the agents into account" — actually argues the opposite of a lingering agent-blind loophole: the authors' point is that any further rule-based improvement would need genuine agent tracking.)

what's missed

Table 1's headline "joint" column (36.5-66.8% on ToMi) blends first-order and second-order questions for both agents into one number; only Table 3 unbundles false-belief from non-false-belief pairs, and that's where the real story is — models are near-ceiling (82.67-100%) on non-false-belief pairs and near-floor (10.40-54.95%) on false-belief pairs specifically. A reader who stops at Table 1 could conclude the models are "moderately okay" at theory of mind; Table 3 shows they aren't solving the false-belief cases that define the task at all, except partially for EntNet.

would raise confidence

No human accuracy ceiling is reported for ToMi, so it's unclear how solvable the randomized, distractor-laden stories are even for a competent human reader (contrast with contemporary benchmarks like Social-IQ, which report a 95.08% human ceiling). Dataset size and train/test split counts are also absent from the six-page main text (deferred to unincluded supplementary material), as is any variance/error-bar reporting across training seeds for the single-run accuracies in Tables 1-3. The paper also notes its own ToM-bAbi reproduction numbers (Table 1) are higher than the original ToM-bAbi paper's, with no resolved explanation ("communication with the authors has not provided clear reasons why") — a minor but unresolved reproducibility flag on the very numbers used to establish the bias claim.

// bottom line

The rule-based-solver demonstration (Algorithm 1) is a clean, convincing proof that ToM-bAbi's rigid templates leak their own answers, and the false-belief-versus-non-false-belief breakdown in Table 3 is the paper's real payload: it isolates exactly where memory-augmented QA models fail on theory of mind, rather than reporting an aggregate number that averages the failure away. The residual 36.5% joint accuracy the same rule-based solver achieves on ToMi, though, is a reminder that even a benchmark built specifically to close known shortcuts can retain unaudited ones — a caution later, richer ToM benchmarks (FANToM's conversational setting, MMToM-QA's multimodal one) were explicitly built to address.

// takeaways

What to remember

  1. ToM-bAbi's three-template story generator embeds giveaway lexical/positional regularities (e.g., the word "exited" only appears in false-belief-type stories); a hand-written four-rule solver with zero agent modeling reaches 100% on both ToM-easy and ToM, proving current QA models weren't demonstrating theory of mind, just pattern-matching the generator.
  2. ToMi replaces the three rigid templates with one randomized, rejection-sampled generator plus distractor agents/objects/locations and shuffled event order, and pairs it with a stricter joint-accuracy protocol (Eq. 1) that scores a story correct only if all six question types about it — reality, memory, first-order ×2, second-order ×2 — are answered correctly.
  3. Under joint accuracy, MemNN/RelNet/EntNet fall from near-ceiling per-question averages to 44.3-66.8% joint accuracy on ToMi; Table 3 shows this collapse is concentrated almost entirely in false-belief question-story pairs (10.40-54.95%), while non-false-belief pairs stay 82.67-100%, isolating the actual theory-of-mind gap.
  4. Even ToMi's fix isn't fully bias-free by the paper's own admission: the same lexical rule-based solver still reaches 36.5% joint accuracy with no agent information at all, and no human ceiling, dataset-size figures, or seed variance are reported — caveats worth carrying into any later comparison against ToMi (as FANToM explicitly does in its own results section).
